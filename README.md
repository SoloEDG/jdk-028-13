## 批量替换（REWRITE）

在原有逐个删除重放之外，实验室支持把一组基础门的两种接法保存为替换规则，并在当前电路中批量应用。

- **规则建立**：在主电路 Shift 多选一组门后点击「从选中区捕获」，模式会自动生成命名边界（INPUT/OUTPUT 节点即边界，边界名取节点 label）；也可以空白新建，在双栏编辑器里分别搭出替换前/替换后接法。
- **等价性证明**：保存前对边界输入枚举全部三值取值（0 / 1 / 悬空 X，共 3^n 种），只有每个边界输出在每种取值下都一致才允许参与匹配；只在当前开关下结果相同不算等价。未通过证明的规则会保存但标记为不可用，并给出反例解释。
- **结构匹配**：匹配只看门类型与连线拓扑，不依赖元件编号或摆放坐标；可交换的双输入脚按等价端口处理；悬空输入脚必须一致；模式未写出、却被外界使用的内部支路会阻止匹配，避免误删。
- **外部扇出**：边界输出的每条外部扇出分支都会完整保留并重接到新接法的对应信号。
- **最优组合与锁定**：重叠匹配之间用分支定界求门成本减少最多的不相交组合；可以锁定必须采用的匹配，锁定项冲突时保留全部锁定项并解释原因，不会擅自删除。
- **预览与生效**：预览在主板上用红色标出拆除部分、绿色标出保留线路，并列出新增元件/连线数量；确认后事务式一次生效并重新检测，取消则原图不动。
- **成本设置**：每种基础门的权重可在规则编辑器里调整，门成本差值决定单次替换的收益。

## 存档兼容

导出文件升级为 `version: 2` 信封，主电路仍是原有 `CircuitDocument` 结构，并额外携带替换规则、成本权重与边界映射。旧的 `version: 1` 实验文件仍按原接法打开（规则集合为空并提示迁移）；浏览器本地存储同时读取新、旧两个键。
